# Example CGM data for 5 subjects with Type II diabetes

Dexcom G4 CGM measurements for 5 subjects with Type II diabetes. These
data are part of a larger study sample that consisted of patients with
Type 2 diabetes recruited from the general community. To be eligible,
patients with Type 2 diabetes, not using insulin therapy and with a
glycosylated hemoglobin (\\HbA\_{1c}\\) value at least 6.5

## Usage

``` r
example_data_5_subject
```

## Format

A data.frame with 13866 rows and 3 columns, which are:

- id:

  identifier of subject

- time:

  date and time stamp

- gl:

  glucose level as measured by CGM (mg/dL)
